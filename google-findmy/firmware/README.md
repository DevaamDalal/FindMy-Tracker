# ESP32 Firmware for Google Find My Device

This directory contains the firmware required to make your ESP32 broadcast as a Google Find My Device tracker.

## Prerequisites

1.  **VS Code** installed.
2.  **ESP-IDF Extension** for VS Code installed and configured.

## Opening the Project

1.  Open VS Code.
2.  Go to `File > Open Folder...` and select this `firmware` directory.
3.  The ESP-IDF extension should recognize it as an IDF project.

## Configuring the Advertisement Key

Before building, you must insert the Advertisement Key generated by the `register_tracker.ps1` script.

1.  Open `main/main.c` (or the relevant source file where the BLE advertisement is defined).
2.  Locate the section defining the advertisement payload or the specific key variable.
3.  Paste the generated bytes into the array.

*Example (Conceptual - exact implementation depends on the C code structure):*
```c
// Replace this with your generated key
uint8_t adv_key[] = { 0x12, 0x34, 0x56, ... };
```

## Building and Flashing (VS Code Extension)

1.  Look at the bottom toolbar in VS Code.
2.  Click the **Select Port** icon (looks like a plug) and choose the COM port your ESP32 is connected to.
3.  Click the **Set Espressif device target** icon (looks like a chip) and select your specific ESP32 model (e.g., `esp32`, `esp32c3`).
4.  Click the **Build, Flash, and Monitor** icon (looks like a flame).
5.  Wait for the process to complete. You should see log output in the terminal confirming the BLE advertisement has started.

## Building and Flashing (Command Line Alternative)

If you prefer using the command line with ESP-IDF environment loaded:

```bash
# 1. Set the target (e.g., esp32, esp32s3)
idf.py set-target esp32

# 2. Build the project
idf.py build

# 3. Flash to the specific COM port (replace COM3) and open monitor
idf.py -p COM3 flash monitor
```

For more detailed visual instructions, see [flash_guide.md](flash_guide.md).
